# SHERR — сайт-портфолио

Одностраничный сайт: первый экран с работами → галерея → прайс → условия (порядок, «рисую / не рисую», вопросы) → обо мне + контакты.
Без сборки и фреймворков — один файл `index.html` + папка `assets`.

## Как открыть

Двойной клик по `index.html` — откроется в браузере.

Чтобы работали шрифты и всё выглядело как на макете, лучше запускать через локальный сервер
(в папке проекта):

```
python -m http.server 8000
```

и открыть `http://localhost:8000`.

```
assets/thumbs/      превью для сетки (1100 px по длинной стороне, качество 86)
```

## Как менять цены

Прайс отдельный для английской ($) и русской (₽) версии — без пересчёта по курсу.
В `index.html` у каждой цены два атрибута:

```html
<b data-usd="55" data-rub="3000">$55</b>
```

- `data-usd` — цена на английской версии;
- `data-rub` — цена на русской версии (пробелы между тысячами ставятся сами).

## Примеры в прайсе

В каждой карточке прайса одна готовая работа-пример (`<button class="card-ex" data-open="…">`).
По клику открывается в просмотре. Чтобы поменять пример — замените `src` у `<img>` и `data-open` у кнопки.

## Слоты на первом экране

В `index.html` найдите:

```html
<div class="status" id="status" data-free="3" data-total="5">
```

`data-free` — сколько слотов свободно, `data-total` — всего. Текст «3 of 5 slots» / «свободно 3 из 5»
собирается сам. Чтобы убрать счётчик, удалите оба атрибута.

## Галерея: что видно сразу

Первые 8 `<figure class="g-item">` показываются сразу, у остальных стоит класс `more` —
они появляются по кнопке «Show all works». Чтобы работа была видна сразу, уберите у неё `more`
и поставьте выше.

## Условия и вопросы

Блок `id="terms"`: шаги заказа, списки «I draw / I don't draw» (`<ul class="yes">` и `<ul class="no">`)
и вопросы-аккордеоны (`<details>`). Тексты — в атрибутах `data-en` / `data-ru`, как везде.

## Как менять тексты

У каждого текста два атрибута: `data-en` и `data-ru`.

```html
<a href="#works" data-en="Works" data-ru="Работы">Works</a>
```

Если правите только один язык — второй останется прежним.
Если атрибута `data-ru` нет, при переключении на русский текст не изменится.

## Как добавить работу

1. Положите файл в `assets/works/` (например `w16.jpg`, 2400 px по длинной стороне, JPG качество ~90).
2. Сделайте превью в `assets/thumbs/w16.jpg` (1100 px по длинной стороне, качество ~86).
   Сохраняйте JPG без «сглаживания» цвета (chroma subsampling 4:4:4), иначе тёмные градиенты и зерно мылятся.
3. В `index.html` в `<div class="gallery" id="gallery">` добавьте строку:

```html
<figure class="g-item"><img src="assets/thumbs/w16.jpg" srcset="assets/thumbs/w16.jpg 1100w, assets/works/w16.jpg 2400w" sizes="(max-width:560px) 100vw, 40vw" width="1100" height="780" loading="lazy" decoding="async" data-full="assets/works/w16.jpg" alt="Описание работы"></figure>
```

Порядок в разметке = порядок в сетке. `width`/`height` — реальный размер превью, `srcset` — ширины превью и большой версии (браузер сам берёт большую, если ячейка крупная или экран чёткий). Сетка сама раскладывает работы по рядам.

## Сетка

Работы выкладываются ровными рядами во всю ширину (как в Flickr / Behance):
картинки не обрезаются, порядок сохраняется, ряды подбираются так,
чтобы не было полупустого последнего ряда.

- ПК: 3–5 работ в ряду (высота ряда ~340–400 px)
- планшет: 2–3 в ряду
- телефон: по одной работе на всю ширину

Высоту ряда можно поменять в скрипте: `var target = W >= 1500 ? 400 : W >= 1020 ? 340 : 270;`.
У каждой `<img>` в галерее должны быть `width` и `height` превью — по ним считается сетка.

По клику открывается лайтбокс с плавной сменой кадров, стрелками ← → и свайпами на телефоне
(влево/вправо — листать, вниз — закрыть).

## Публикация (GitHub Pages)

Адрес сайта: **https://apollinarissherr.github.io/portfolio/**

1. Войдите на github.com под аккаунтом `apollinarissherr`.
2. Создайте публичный репозиторий с именем `portfolio` (New repository → Public).
3. В репозитории: **Add file → Upload files** и перетащите содержимое папки
   `sherr-portfolio`: `index.html`, `.nojekyll`, папку `assets` (README и WORKS-MAP — по желанию).
   Файл `_wide-test.html` загружать не нужно — это тест.
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт откроется по адресу выше.

Обновление: загрузите изменённые файлы тем же способом (Upload files) — Pages пересоберётся сам.

Бесплатные альтернативы: Netlify Drop (app.netlify.com/drop — перетащить папку)
или Cloudflare Pages. Ссылки в `og:image` / `canonical` в `index.html` указывают на GitHub-адрес —
при переезде их нужно поменять.
